# chunyu_data

This dataset is associated with our paper, titled:
"A Longitudinal Physician Dataset with Multimodal Consultation-derived Features from a Chinese Online Healthcare Platform".

## Physician Profile Feature
The Physician Profile Feature directory contains the longitudinal physician–week profile panel.

## Derived Variables
The Derived Variables directory contains derived variables at consultation and weekly level.

## Supplementary Data
This directory contains supporting resources required to interpret or reproduce the released variables.

## code
This directory provides Python code utilized for dataset construction.
