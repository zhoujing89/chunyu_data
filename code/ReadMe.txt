"profile_feedback.py" includes Python code for the construction of the Physician Week Profile Panel, the construction of Weekly Service Use and Feedback Indicators, and the anonymization code.

“Multimodal_Feature.py” comprises the code for the preprocessing of the online consultation data, as well as the construction of multimodal features based on the consultation records.

The Python code involved in the technical verification procedures is recorded in the script “technical verification.py”.
